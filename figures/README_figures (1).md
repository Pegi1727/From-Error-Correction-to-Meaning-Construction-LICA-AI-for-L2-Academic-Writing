# Figures — From Error Correction to Meaning Construction: LICA-AI for L2 Academic Writing

This folder contains all publication-ready figures for the manuscript, plus
"check_"-suffixed JPEG preview/proofing copies of each main figure. All files are
rendered at **300 DPI** (print resolution) with embedded DPI metadata.

## Captions (suggested manuscript text)

- **Figure 1.** Inter-rater reliability of writing assessments: ICC estimates with 95%
  confidence intervals for human raters, the LICA-AI system, and human–AI agreement.
- **Figure 2.** Individual and mean pre–post trajectories of L2 academic writing
  performance across the intervention period for the LICA-AI and control conditions.
- **Figure 3.** Fixed-effect interaction coefficients (Condition × Time) from the
  statistical models of writing outcomes; bars/points show estimates with 95% CIs.
- **Figure 4.** Standardized effect sizes of the intervention on each writing outcome,
  comparing within- and between-group changes.

## Resolution and formats

- Main figures: PNG, 300 DPI (embedded), RGB, suitable for print and web.
- Check files: JPEG, 300 DPI (embedded), provided as lower-filesize proofing copies.
- Recommended minimum print widths at 300 DPI are preserved by the pixel dimensions above.

## Data source

All figures are generated from the replication materials bundled with this repository:
`lica_ai_rater_raw.csv` (raw human and LICA-AI ratings) and the processed dataset
`lica_ai_data_processed.csv` derived from it (also packaged in
`lica_ai_replication_data.zip`). Statistics and plots can be reproduced with the
analysis scripts/notebooks in the repository root and `notebooks/` folder.
